# AITADZ Primary School English Teacher Assistant (`aitadz.pro`)

A production-ready, cloud-deployable Python Telegram Bot built for **AITADZ (`aitadz.pro`)** that generates **100% Didactic-Guide-compliant, print-ready A4 `.docx` lesson plans** for Algerian Primary School English teachers (**3PS / Year 3**, **4PS / Year 4**, and **5PS / Year 5**).

---

## Pedagogical Compliance (Algerian Ministry / CNP Didactic Guides)

Every lesson plan strictly follows the official Algerian Ministry of National Education / National Curriculum Council (CNP) Didactic Guides:
- **Key Stage 1 (`3PS` & `4PS`)** — *Didactic Guide of English - Key Stage 1 Primary Education (2023)*
- **Key Stage 3 (`5PS`)** — *Didactic Guide of English - Key Stage 3 Primary Education (2024)*

### Enforced Rules (`didactic_rules.py`)
1. **Level-Specific Session Budget:** **60 minutes** for Year 3 (`3PS`) and Year 4 (`4PS`), and **45 minutes** for Year 5 (`5PS`) across official stages.
2. **Official Metadata & Layout (`KS1 p. 75` / `KS3 p. 86`):**
   - Level, Class Profile, Number of Learners, Duration (`60 mn` for 3PS/4PS; `45 mn` for 5PS), Sequence, Section, Session, Domain(s), Target Competence, Session Objective(s) (*"By the end of the session, learners will be able to..."*), Subsidiary Objective(s), Phonics / Language Focus, Core Values, Cross-Curricular Competencies, Teaching Materials (VAKT), Anticipated Problems, Solutions / Plan B, and Self-Reflection (`What worked`, `What hindered`, `Action plan`).
3. **Grade-Specific Constraints:**
   - **3PS (6 Sequences, 4 Sessions/Section):** Print/script handwriting only by formation families (no cursive, no free paragraphs), no written text on the board during Session 1 (*I Sing & Have Fun / I Listen & Repeat*), VC/CVC phonemic awareness only, no sight words. Project: *My Pictionary*.
   - **4PS (5 Sequences, 5 Sessions/Section):** Includes *I Read & Enjoy* reading games; *I Read & Write* targets completing topic-related forms in connected/joined (cursive) handwriting (not free essays). Project: *Mini Dictionary*.
   - **5PS (3 Sequences, 9 Session Types):** Writing for reinforcement (~10/15/20 words from form notes, not free essays), multiple listening passes, chunked reading checking *how* answers were found, finger word boundaries, Exit Ticket reflection, and portfolio continuity (*I Get Ready* → *I Check My Progress*). Project: *My Booklet*.
4. **Zero Meta-Language & Implicit Grammar:** No explicit grammar rule lectures; learner-facing meta-terms (`skim`, `scan`, `gist`, `prediction`) are automatically scrubbed.
5. **Non-Monetary Classroom Gamification:** Strictly child-appropriate rewards (**Gold Stars**, **Explorer Badges**, **Team Points**, **Stickers**, **Smiley/Traffic Cards**) — never monetary prizes or financial tokens.

  - Deep Navy (`#0D1B2A`) & Primary Blue (`#0056D2`) headers with bold Neutral White (`#FFFFFF`) typography

  - Alternating Soft Gray (`#F5F7FA`) table row shading
- **Sections:** AITADZ Banner → Official Didactic Metadata Grid → 5-Column Procedure Table (`Time | Stage | Procedure / Teacher & Learner Tasks | Interaction | Competency / Materials`) → Formative Exit Ticket & Non-Monetary Gamification Box → 3-Panel Visual Whiteboard Layout → Self-Reflection Grid → Branded Footer with Page Numbering (`"Generated by AITADZ Teacher Assistant (aitadz.pro)"`).

## Cloudflare MCP Server Portal Integration (`mcp_client.py` & `cloudflare-mcp-server/`)

Requests are sent to `CLOUDFLARE_MCP_PORTAL_URL` authenticated via Cloudflare Access Service Token headers:
```http
CF-Access-Client-Id: <CF_ACCESS_CLIENT_ID>
CF-Access-Client-Secret: <CF_ACCESS_CLIENT_SECRET>
```
If the portal is unconfigured in local development or temporarily unreachable, `mcp_client.py` gracefully falls back to the local Didactic Guide synthesizer (`didactic_rules.py`) so teachers always receive a valid, compliant `.docx`.

### Deploying Your Cloudflare MCP Server & Creating an MCP Portal

1. **Deploy the Worker (`cloudflare-mcp-server/`):**
   ```bash
   cd cloudflare-mcp-server
   npm test
   npx wrangler login
   npx wrangler deploy
   ```
   Wrangler will deploy `aitadz-mcp-server` with native **Cloudflare Workers AI** (`@cf/meta/llama-3.3-70b-instruct-fp8-fast`) and print your Worker URL (e.g., `https://aitadz-mcp-server.<your-subdomain>.workers.dev`).

2. **Create a Cloudflare Zero Trust Service Token:**
   - Open **Cloudflare One / Zero Trust Dashboard → Access → Service Auth → Service Tokens → Create Service Token**.
   - Copy the generated **`CF-Access-Client-Id`** and **`CF-Access-Client-Secret`**.
   - *(Recommended defense-in-depth)* Bind the same credentials on the Worker too:
     ```bash
     npx wrangler secret put CF_ACCESS_CLIENT_ID
     npx wrangler secret put CF_ACCESS_CLIENT_SECRET
     ```

3. **Register the Server in Cloudflare MCP Portals (or Access App):**
   - Go to **Cloudflare Zero Trust → Access → AI Controls / MCP Portals** (or **Access → Applications → Add Self-hosted Application** for your Worker domain).
   - Register your Worker MCP endpoint: `https://aitadz-mcp-server.<your-subdomain>.workers.dev/mcp`.
   - Attach an Access policy allowing **Service Auth** (`Service Token` created in Step 2).
   - Set these 3 values in your Telegram Bot's `.env` / Render environment:
     - `CLOUDFLARE_MCP_PORTAL_URL` = your Portal MCP URL (or `https://aitadz-mcp-server.<your-subdomain>.workers.dev/mcp`)
     - `CF_ACCESS_CLIENT_ID` = Service Token Client ID
     - `CF_ACCESS_CLIENT_SECRET` = Service Token Client Secret

## Cloud Deployment (Render.com) & UptimeRobot

1. Push this repository to GitHub/GitLab.
2. In **Render Dashboard**, choose **New + → Blueprint**, connect the repo, and confirm `render.yaml`.
3. Fill in the secret environment variables:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_WEBHOOK_SECRET` (generate e.g. with `openssl rand -hex 32`)
   - `WEBHOOK_BASE_URL` (e.g. `https://aitadz-lesson-bot.onrender.com`)
   - `CLOUDFLARE_MCP_PORTAL_URL`
   - `CF_ACCESS_CLIENT_ID`
   - `CF_ACCESS_CLIENT_SECRET`
4. **UptimeRobot Keep-Alive:** Create an HTTP(s) monitor hitting `GET https://your-service.onrender.com/health` every 5 minutes (expects `200 OK` JSON `{"status": "ok", "service": "aitadz-lesson-bot"}`).

## Telegram Webhook Registration (`curl`)

Register the webhook with your secret token (`X-Telegram-Bot-Api-Secret-Token`):

```bash
curl -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "'"${WEBHOOK_BASE_URL}"'/webhook",
    "secret_token": "'"${TELEGRAM_WEBHOOK_SECRET}"'",
    "allowed_updates": ["message", "callback_query"]
  }'
```

Verify webhook status:

```bash
curl -s "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/getWebhookInfo"
```

Verify server health endpoint:

```bash
curl -s "${WEBHOOK_BASE_URL}/health"
```
